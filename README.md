# Myntra Clone

A modern e-commerce website clone built with HTML, CSS, and JavaScript. This project replicates the design and functionality of the popular Indian fashion e-commerce platform Myntra.

## Features

- **Responsive Header** - Navigation bar with search functionality, profile, wishlist, and shopping bag
- **Product Showcase** - Category and offers display with scrollable items
- **Clean Design** - Modern UI with Material Design icons
- **Organized Layout** - Header, main content area, and footer structure

## Project Structure

```
├── index.html      # Main HTML file
├── index.css       # Styling
├── images/         # Image assets
│   ├── categories/ # Category images
│   ├── offers/     # Offer images
│   ├── banner.jpg
│   └── myntra_logo.webp
└── README.md       # This file
```

## Getting Started

1. Clone this repository:
   ```bash
   git clone https://github.com/yourusername/myntra-clone.git
   cd myntra-clone
   ```

2. Start a local server:
   ```bash
   python -m http.server 5500
   ```

3. Open your browser and navigate to:
   ```
   http://localhost:5500
   ```
